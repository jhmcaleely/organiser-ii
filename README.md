# organiser-ii

In the 1990's I wrote and distributed software for the Psion Organiser II computer. Here are two programs I have recently rediscovered the source for.

The routine DATIN: was supplied by David C. Jones in 1994, for distribution as part of these software packages.

The files ann.opk and todo.opk can be used in an emulator like: https://www.jaapsch.net/psion/jape/jape.htm to run this software.
